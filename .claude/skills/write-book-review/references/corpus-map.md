# 책 리뷰 코퍼스 인덱스

writer/reviewer 는 초안을 쓰거나 채점하기 전에, 판정된 category 의 **주 모델 1편을 전문 정독**하고
나머지 1편도 도입·마무리 구간은 반드시 읽는다. 화법·전개의 기준선은 항상 실제 코퍼스다.

| 파일 (`apps/web/content/posts/ko/`)   | category | 주 모델이 되는 경우 | 전개 특징                                                                                                                                                                                                                                          |
| ------------------------------------- | -------- | ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `book-review-growing-together.mdx`    | life     | life 책 리뷰        | 독자에게 질문 → 개인 고민(연차·성장) → 책을 받게 된 계기 → `## 책 소개`(3부 구성) → `## 책 리뷰` 파트별 `### N부. 키워드 -> 질문` 안에서 **요약 → "뼈맞은 기분" → 경험 → 결심** → `## 끝으로`(읽은 시기 고백, 세 축으로 수렴, 독자에게 질문, 응원) |
| `harness-engineering-with-claude.mdx` | tech     | tech 책 리뷰        | 실무 고민 → 책을 읽게 된 계기 + 책의 관점 한 줄 → 표지 → `# 주요 내용` 아래 개념별 `##`(인용 `>`, 표, 볼드 리드) → `## 적용해보기`(직접 만든 하네스) → `## 마치며`                                                                                 |

## 관찰된 공통 장치

- 책 제목 `「」`, 첫 등장에 알라딘 링크 + (출판사, 연도).
- 저자 주장 전달 화법: "저자는 ~라고 강조합니다 / 제시합니다 / 짚습니다".
- 요약에서 경험으로 넘어가는 전환 문장: "책 초반부 부터 뼈맞은 기분이었습니다.", "저 역시 ~ 편이기 때문에".
- 경험 뒤 깨달음: "그렇게 저는 **~해야 한다**는 생각에 이르렀습니다." — 핵심 결론은 볼드.
- 마무리는 책의 메시지를 몇 개의 축으로 수렴 → 개인 다짐 → 독자에게 질문 → 추천.

## 이미지 참조 규약

코퍼스는 `![설명](/images/posts/<slug>/<name>.jpg)` 로 표지를 넣는다.
**이 스킬은 이미지를 생성하지 않는다.** `{/* TODO: 책 표지 — /images/posts/<slug>/cover.jpg */}` 주석만 남기고,
publish 보고 시 사용자에게 이미지 추가를 안내한다.
